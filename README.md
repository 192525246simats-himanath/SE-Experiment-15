\# SE Experiment 15

\## GitHub Repository and Version Control



\### Project Description

This project demonstrates Git and GitHub version control

using a team-based software development workflow.



\### Modules

1\. User Management

2\. Login Management

3\. Dashboard Management



\### Git Workflow

\- Create a GitHub repository.

\- Clone the repository locally.

\- Create individual branches for modules.

\- Make changes and commit them.

\- Push branches to GitHub.

\- Create Pull Requests.

\- Review and merge changes.

\- Resolve merge conflicts.



\### Technologies Used

\- Git

\- GitHub

\- Command Prompt



\### Conclusion

This experiment demonstrates collaborative development,

branch management, pull requests, and conflict resolution

using Git and GitHub.
